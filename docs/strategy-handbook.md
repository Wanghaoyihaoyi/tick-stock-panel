# 策略手册与独立研究版本

应用导航中的 **策略手册**（`/strategy-handbook`）分为短线策略与中长期研究。导航较长时可滚动左侧菜单。全部原策略保留，未设置自动实盘或改变实时监控。

## 当前保留清单（2026-09-12 整理）

按用户要求，以本轮验证段收益对比为准，已移除 10 个恶化研究版及对应候选，保留 15 个改善版，并将显示名称前缀改为“改善”，例如“改善·断板反包·核验版”。名称通过现有策略配置接口更新，策略 ID、算法及交易参数不变。原始内置策略和此前的半仓等方案均保留。

“改善”只表示该段历史收益高于原版；其中逼近涨停、连板股、MACD 金叉放量、MACD 零下回升的回撤仍有所扩大。全部保留版仍为待验证研究候选。

移除名单：新低反转、MA 金叉、连板接力、长下影反击、RSI 中轴回踩、放量创60日新高、超跌反弹、布林突破、均线粘合突破、强势高开的本轮核验版。手册仍保留原策略说明和标注“已移除”的历史对照，取消已移除研究版的候选载入说明。

原始 125 组研究结果留作复盘，未删除。该批次的 `curation.json` 记录当前清单，`curation-verification.json` 记录整理后核对结果；下文 25 个新版的描述指首次实验的历史规模。已整理批次禁止再次运行生成器的 `install` / `candidates` 阶段，以免重新引入已移除版本。

## 日常查看与执行

1. 在短线栏目按策略名或 ID 搜索，查看原始触发、退出、已识别风险和新版改进。页面涵盖 25 个普通内置策略和 1 个隐藏因子研究模板。
2. 当前保留版统一叫 `改善·原名称·核验版`，ID 为 `custom_hb0912_原ID`。它们是真正改变信号的独立策略；“核验”指补充条件，不表示盈利或投资质量通过验证。
3. 进入回测 → 候选方案，按完整新版名称查找并载入复测。当前保留 15 个本轮待复核候选。核对日期、全部股票池、交易成本、原生止损/持有期限，再运行。页面链接不会自动选择策略或下单。
4. 策略筛选页也可以选择新版。信号在收盘后确认，回测最早次日开盘成交，不代表当天开盘时已知结果，也不保证涨停板可以买入。
5. 勾选的检查清单可以导出 Markdown。中长期栏目按股票代码填写企业证据、现金流/负债、估值假设、安全边际、反证与复核日期。记录只存在当前浏览器，刷新后可按代码重新打开；应导出备份。

## 原则与数据边界

中长期研究借鉴巴菲特和芒格的企业所有者视角，围绕能力圈、持久竞争优势、所有者收益、合理估值及反证复核展开。具体步骤是本手册的实施解释，不是大师背书的量化公式。原始资料链接已放入页面：

- [1996 年股东信：能力圈](https://www.berkshirehathaway.com/letters/1996.html)
- [2023 年股东信：回顾芒格与优质企业](https://www.berkshirehathaway.com/letters/2023ltr.pdf)
- [2007 年股东信：护城河与资本回报](https://www.berkshirehathaway.com/letters/2007ltr.pdf)
- [1986 年股东信：所有者收益](https://www.berkshirehathaway.com/letters/1986.html)
- [1992 年股东信：估值与安全边际](https://www.berkshirehathaway.com/letters/1992.html)
- [1994 年股东信：内在价值](https://www.berkshirehathaway.com/letters/1994.html)

2026-09-12 检查时，本地 `financials` 无财务 Parquet。系统已有按公告日对齐的财务因子能力，但本轮不能进行有证据的多年基本面回测。手册不把日线筛选冒充价值投资，不使用人工研究记录或股东评估回填历史信号。缺失证据仍须补齐，填写完成也不等于买入批准。

## 本轮回测口径

- 25 组固定改进，未对参数进行收益择优。原版/新版各跑训练段（2026-01-05—2026-05-29）及验证段（2026-06-01—2026-09-11）；新版额外跑验证段双倍滑点，共 125 组。另做 1 次真实应用 API 复测，核对断板反包新版的收益、回撤、交易数一致。
- 全股票池、100 万元、最多 10 股等权、总仓位上限 100%、次日开盘进出。保持各策略声明的原生评分、止损和持有期限，因此不同策略间不能只用收益排名；原版基线未使用此前个人保存的覆盖设置。
- 佣金 0.02%，卖出印花税 0.1% 是延续旧实验的固定成本假设，并非当前税率声明。滑点 5bp，压力测试 10bp；实际使用请按真实成本修改。
- 历史此前已被查看，不能称为盲测样本外。当前证券元数据存在历史 ST/退市及生存者偏差，约一年行情不能证明长期复利。
- 15 个新版验证段收益高于原版，10 个更低；只有 MACD 零下回升新版略为正收益（0.37%），双倍滑点后为 -0.37%，训练段为 -11.64%。无新版同时在训练、验证和费用压力下保持正收益，本轮没有晋升实盘策略。
- 手册是注明日期的研究快照，后续重新回测不会自动改写其结果。所有失败结果保留，不能只摘录变好的案例。

## 实现与复现

- 前端只新增 `frontend/src/custom/strategy-handbook/`，通过已有 L2 扩展注册路由和导航，不改核心页面、API 或查询键。
- 短线策略使用已有 L1 自定义文件契约，新增到 `data/strategies/custom/`。生成器为 `scripts/strategy_handbook_research.py`；规则固定在 `RULES`，每个原策略一个可解释假设，退出和评分保留。新低反转改为触及并收复支撑，平台振幅分母改为昨日收盘并要求完整窗口，其余主要增加入场确认。
- 默认回测预热至少 65 根有效日线，用以计算新增 MA60 斜率等条件；全程使用 `valid_shift`，不以自然日零值填充停牌。
- 部分内置评分字段（例如 `limit_up_count_60d`）不在 AI 编辑器的窄字段校验表中，因此通过 L1 自定义目录安装，并验证实际 StrategyEngine 加载、信号和回测调用链；没有修改 AI 编辑器校验。
- `data/` 被 Git 忽略。提交代码不会自动携带行情、策略文件及候选记录，迁移时需单独处理。研究手册 JSON 会进入前端构建。
- 本轮原始审计、计划、代码副本、125 份结果和校验记录在 `data/user_data/backtest_research/master-strategy-guide-20260912-01a09495/`。它使用独立代码/数据副本与缓存，低优先级、有限线程运行；没有停止其他任务的 worker。

生成器有四个阶段：`prepare`、`install`、`run`、`candidates`。`prepare --output <新的独立目录> --data-snapshot <只读数据副本>` 会复制代码和数据并锁定计划；输入/输出不可嵌套。各阶段用 `backend/.venv/bin/python scripts/strategy_handbook_research.py` 调用。安装使用排他创建，不覆盖已有 ID；本环境已安装，不要重复安装。`run` 可从已有结果继续，候选写入走应用接口以保留其他任务的数据。API 地址使用项目本地默认端口 3018。

验证命令（在项目根目录）：

```sh
PYTHONPATH=backend POLARS_MAX_THREADS=2 OPENBLAS_NUM_THREADS=1 backend/.venv/bin/python -m pytest scripts/test_strategy_handbook_research.py backend/tests/backtest/test_research_candidates.py backend/tests/test_strategy_scoring.py -q
backend/.venv/bin/ruff check scripts/strategy_handbook_research.py scripts/test_strategy_handbook_research.py --select E,F,I --ignore E501
```

前端在 `frontend` 目录运行 `pnpm build`。浏览器验收还覆盖搜索、展开对照、研究记录保存/刷新恢复/导出和窄屏布局。
