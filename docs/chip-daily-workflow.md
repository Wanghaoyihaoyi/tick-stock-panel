# 筹码策略日常使用流程

## 日常选股

1. 收盘后在「数据」页确认日线和指标数据已更新到最新交易日。数据源 API 负责获取行情, 本地数据库保存行情供策略计算; 不需要每天用 Computer Use 逐只扫描。
2. 在「策略」页选择最新已入库的交易日, 点击「筹码峰·股东核验」。列表数量表示技术候选数, 不是最终核验通过数。
3. 打开候选股详情, 展开「股东与公告核验」, 将资料截止日设为选股日期, 点击「联网核验」。同日已保存的报告可以直接查看。
4. 联网结果属于模型草稿。核对报告期、公告日、两期股东数据和风险原文后, 才能生成复核评分记录。当前点击联网按钮不会自动批准评分; 日期、策略代码或参数变化后需重新复核, 不沿用旧分。
5. 对照综合评分、缺项和否决事项整理观察名单。「待核验」表示资料不足, 不能当作最终通过。

## 回测设置

- 在「回测」中选「筹码峰·股东核验」, 先用近三个月检查流程。结束日期可选最新有行情的交易日。
- 目前回测只验证筹码和趋势技术信号, 不包含事后新增的股东核验分。交易明细中的评分仍是技术排序分, 不是选股页面的综合参考分。
- 「全量模拟」用于逐笔评估所有历史候选; 「仓位模拟」用于检查资金、持仓数量限制后的账户结果。两者结果不能直接混比。
- 日线收盘后产生信号的场景, 建仓和清仓可选「次日开盘」。佣金、印花税和滑点按自己的实际成本设置, 保留策略止损和持有期规则。
- 本地没有分钟历史时关闭「分钟成交」。需要分钟成交时, 先同步覆盖整个回测区间的分钟数据。
- 预热是正式回测开始之前的历史行情, 不是需要用户等待的天数。本策略默认使用160根有效日线预热, 还需覆盖正式回测区间; 页面通用的“≥120天”不是该策略的精确要求。
- 延长至半年或一年之前先补足更早的历史日线及指标。不要只拿今天筛出的三只股票回测后当作整个策略表现, 这样会引入事后选择偏差。

## 2026-09-12 报错修复

回测共用缓存曾把所有注册策略的数值参数同时替换为最大值, 破坏了筹码策略 strong < mild 等关联约束, 导致其他策略也被阻断。现改为: 最大值组合不合法时用默认参数准备通用缓存, 并始终合入实际回测请求的依赖。实际错误参数仍会被校验拒绝。
